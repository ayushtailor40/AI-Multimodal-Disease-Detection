About the Research Project

Academic Research Prototype

1. Project Title & Overview

Project Title: “An AI-Based Multimodal Approach for Early Disease Detection”

Traditional diagnostic workflows rely primarily on unimodal algorithms that process medical images in isolation from the patient's presenting symptoms and physiological vital signs. This project proposes a comprehensive multimodal clinical decision-support framework that combines deep convolutional image features (EfficientNet-B0), natural language processing (TF-IDF + classification) for clinical symptom narratives, and standardized tabular machine learning for vital signs, integrated via a calibrated late-fusion consensus.

2. Technology Stack

  • Programming Language: Python 3.13
  • Web Application Framework: Flask (WSGI, Jinja2 templating, secure upload streaming)
  • Deep Learning Engine: TensorFlow 2.x & Keras 3.x (EfficientNet-B0 transfer learning backbones)
  • Machine Learning & Statistics: Scikit-learn (LogisticRegression, TfidfVectorizer, StandardScaler, classification metrics)
  • Medical Image Processing & XAI: OpenCV (cv2) and Pillow (PIL) for image resizing, format verification, and Grad-CAM colormapping
  • Frontend Architecture: Responsive HTML5, modern CSS3 design system, and Vanilla JavaScript with drag-and-drop file upload and instant image previewing

3. Multimodal Decision Fusion Architecture

For the Pneumonia pipeline, decisions are merged via a weighted linear late-fusion strategy. The final probability for class \(c\) (where \(c \in \{\text{NORMAL}, \text{PNEUMONIA}\}\)) is defined as:

P_final(c) = w_img * P_img(c) + w_text * P_text(c) + w_clinical * P_clinical(c) Where: w_img = 0.40 (40% weight assigned to deep Chest X-Ray radiograph features) w_text = 0.30 (30% weight assigned to TF-IDF symptom text narrative) w_clinical = 0.30 (30% weight assigned to standardized physiological vitals)

This late-fusion architecture provides robust fault tolerance: if an image presents subtle or ambiguous opacities, high-fidelity symptom reports and elevated physiological biomarkers (e.g. fever, tachypnea, low SpO2) ensure sensitive detection.

4. Explainable AI: Grad-CAM Implementation

To demystify deep convolutional "black-box" predictions, the framework incorporates Gradient-weighted Class Activation Mapping (Grad-CAM). Grad-CAM computes the gradient of the winning class score \(y^c\) with respect to the feature maps \(A^k\) of the last convolutional layer (top_conv in EfficientNet-B0):

α_k^c = (1 / Z) * Σ_i Σ_j (∂y^c / ∂A_ij^k) Heatmap = ReLU( Σ_k α_k^c * A^k )

The resulting activation map is normalized, upsampled via bilinear interpolation to \(224 \times 224\), and overlaid onto the chest radiograph using a JET colormap.

5. Autonomous Disease Modules

The dashboard features four distinct clinical pipelines:

  1. Pneumonia + Multimodal Fusion: Tri-modal analysis on chest radiographs, patient symptoms, and vital signs.
  2. COVID-19 Radiography Classifier: 4-class differential diagnostic tool (COVID-19, Lung Opacity, Normal, Viral Pneumonia).
  3. Tuberculosis (TB) Screening Classifier: 2-class binary radiograph screener achieving 99.21% test accuracy.
  4. Lung Cancer CT Histopathology Classifier: 3-class axial CT scan classifier distinguishing benign nodules, malignant carcinomas, and normal parenchyma.

Displayed probability percentages represent uncalibrated model softmax activations and must not be interpreted as certified medical probabilities. No clinical diagnosis should ever be made without the physical examination, laboratory testing, and formal interpretation of a qualified licensed healthcare physician.
